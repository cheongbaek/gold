## 1. 신호 규칙 (현시정보 PDF 마지막 쪽 · 엑셀 머리)
- **주기 100 s. 레이스 출발(0 s)에 전 교차로가 1현시를 시작한다.** — 모든 신호가 같은 시계를 쓴다.
- 표의 `27(3)` = 그 방향 녹색 27 s + 황색 3 s. 적색은 적지 않는다(나머지 = 적색).
- 엑셀의 녹색 시간은 **순수 녹색**(황색 3 s 제외). '실제로 쓰는 녹색 창' 이 100 을 넘으면 **다음 주기**의 창을 쓴다는 뜻이다(그 신호에 닿는 시각 기준).

## 5. 저장소와의 대조 (2026-10-09)
- 본선 신호 순서·교차로·좌회전 두 곳(#400 B · #1100 A)·녹색 창 T1~T4 는 `white1/traffic_timer.py SIGNAL_WINDOWS` 와 **같다.**
  T5 는 코드 0~57(카메라), 문서 0~37 · 40~57.
- **예선 신호 시각표(85~97 · 0~37)는 저장소에 없다** — 예선(서브 코스)은 지금 카메라로만 판단한다.
- 시계 0 = **레이스 출발**. white1 타이머는 0초를 T1(또는 T2) 의 적→녹 전환으로 잡는다 — 문서와 같은 시계다(본선 1번 녹색이 0 s 에 시작).
- 예선 S 두 곳의 정지선 = 맵 차로 첫 노드 **#1400 Lane1**(경로 s 224.9 m) · **#1500 Lane21**(317.7 m) — 경로 위 0.4·0.5 m.
  `subcourse.csv` 의 S 행은 그보다 **6.2 · 6.5 m 앞**(218.7 · 311.2 m). 9/13 예선 주행(`ros2bag/route_20200202_222223-20260913_140402.csv`)은
  정지선 **2.3 · 3.2 m 앞**에 섰다(미션 '정지선 5 m 안 3 초 이상' 충족). 속도를 올리면 2단 정지거리가 늘어 이 여유가 줄어든다.
